# User guide

Simple Aircraft Manager keeps the records and status of a small fleet: hours, squawks, components, the maintenance logbook, inspections, ADs, documents, oil and fuel, weight and balance. It works out whether each aircraft is airworthy from those records. This guide explains how to use it, for everyone who flies, maintains or administers the aircraft.

The same pages are in the app under **Help** in the menu.
